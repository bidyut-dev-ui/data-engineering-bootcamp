# Project 01.5: Object-Oriented Python (OOP) for Data Automation

## Overview
In Data Engineering, you often move from simple scripts to complex automation frameworks. Object-Oriented Programming (OOP) allows you to build reusable, maintainable, and scalable components like custom database clients, API wrappers, and pipeline operators.

This module covers the core OOP concepts specifically through the lens of Data Engineering.

## Learning Objectives
- Master **Classes and Instance Variables** to manage pipeline state.
- Understand the difference between **Instance, Class, and Static methods**.
- Learn when to use **Inheritance vs. Composition** (the "Is-A" vs. "Has-A" relationship).
- Implement **Abstract Base Classes (ABCs)** to enforce data contracts.
- Build a reusable **DatabaseClient** framework.

## Project Structure
- `01_classes_and_objects.py`: Foundation of Python classes.
- `02_methods_and_decorators.py`: Instance, @classmethod, and @staticmethod.
- `03_inheritance_and_composition.py`: Building complex systems from simple parts.
- `04_abstract_base_classes.py`: Creating interfaces for your data loaders.
- `practice_exercises.py`: Hands-on challenges.
- `GOTCHAS_BEST_PRACTICES.md`: Common OOP pitfalls in DE.
- `INTERVIEW_QUESTIONS.md`: Senior-level OOP interview prep.
