## 🎯 The Rubyist's Path to Data Engineering

This bootcamp is specifically designed for developers coming from an OO/Web background (Ruby on Rails, Node.js) who want to master the distributed, data-intensive systems required in modern enterprises.

### **1. Enterprise Data Engineering & ETL**
- **Core Skills:** Designing fault-tolerant ETL/ELT pipelines, Data Modeling, and Star Schemas.
- **The Tech Stack:** **Apache Airflow**, **dbt**, and **PostgreSQL**.

### **2. Production Engineering & Leadership**
- **Core Skills:** Observability, Security, CI/CD, and Incident Response.
- **The Tech Stack:** **Prometheus**, **Grafana**, **Terraform**, and **GitHub Actions**.

### **3. Generative AI & ML Architecture**
- **Core Skills:** Vector Databases, RAG (Retrieval-Augmented Generation), and Model Serving.
- **The Tech Stack:** **LangChain**, **FastAPI**, and **pgvector**.

## 📚 Curriculum Overview

### **Month 1: Python & Data Processing**
- Week 1: Environment Setup & Python Refresher
- Week 1.5: Python Deep Dive (Iterators, Generators)
- Week 1.75: **[Lead]** Python OOP & Architecture Patterns
- Week 2-3: Data Manipulation with Pandas (Chunking, Memory Optimization)
- Week 4: **Project 1** - The Data Janitor (CLI Cleaning Tool)

### **Month 2: Databases & SQL**
- Week 5: Dockerizing Postgres & SQLite
- Week 6: Advanced SQL (CTEs, Window Functions)
- Week 7: Data Modeling (Star Schema, Normalization)
- Week 8: **Project 2** - Warehouse Builder (ETL to Postgres)
- Week 8.5: **[Lead]** Data Reliability (ACID, Idempotency)

### **Month 3: Orchestration & Infrastructure**
- Week 9-11: Airflow Platform (DAGs, Sensors, Error Handling)
- Week 11.5: **[Lead]** Infrastructure as Code (Terraform)
- Week 12: **Project 3** - Orchestrated ETL
- Week 12.5: **[Lead]** Schema Evolution & Data Contracts

### **Month 4: The Modern Data Stack & APIs**
- Week 13: Advanced PySpark (Memory & Query Optimization)
- Week 14: **[Lead]** dbt Fundamentals (Data Build Tool)
- Week 15: FastAPI & Pydantic V2 Mastery
- Week 16.5: **[Lead]** Real-time Streaming (Redpanda)
- Week 17: **Project 4** - Data API Service

### **Month 5: AI Platform Engineering**
- Week 18: Statistics for Data Engineers
- Week 19: **[Lead]** Vector Databases & Similarity Search
- Week 19.5: LangChain & RAG Architecture
- Week 20: **Project 5** - Predictive Service

### **Month 6: Capstone & Reliability**
- Week 21-24: Capstone Implementation (End-to-End Platform)
- Week 25: **[Lead]** Tested Pipelines (Pytest, Great Expectations)
- Week 26: **[Lead]** Monitored Platforms (Prometheus, Grafana)

### **Month 7: Team Leadership & Job Prep**
- Week 27: **[Lead]** Security & Governance (PII Masking, RBAC)
- Week 28: **[Lead]** Incident Response & On-Call Playbooks
- Week 29: **[Lead]** Data Lineage & Profiling
- Week 30: **[Lead]** CI/CD & Deployment
- Week 31: Interview Mastery & Live Coding Practice
